# Yeezy
A minimal smart directory jumper that aims to replicate (most of) the functionality of zoxide.

## Current state
Yeezy is useable on a daily basis (at least I do). There might be bugs, and features are incomplete.

## Getting started
1. Configure the program in `config.h`.

2. The makefile can be modified based on your needs. Otherwise, just `make && make install`.

3. Copy the shell templates in the templates directory and place them below your shell prompt or PS1.
